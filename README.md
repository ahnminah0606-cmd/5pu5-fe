# 5PU5 React

5PU5 기존 시안의 디자인과 동작을 React로 옮긴 로컬 개발 프로젝트입니다.

## 실행

Node.js 20.19 이상(22 버전은 22.12 이상)이 필요합니다.

```sh
npm install
npm run dev
```

브라우저에서 http://127.0.0.1:8080/ 를 엽니다. 코드를 수정하고 저장하면 화면에 반영됩니다. 8080 포트를 다른 프로그램이 사용 중이면 서버가 시작되지 않으므로 해당 프로그램의 포트를 확인하세요.

## 주요 파일

- `src/App.jsx`: 화면 상태, 필터, 비교표, 출처 창, 시연용 로그인·채팅 연결
- `src/components/Landing.jsx`: 시작 화면, 소개, 푸터
- `src/components/GpuCard.jsx`: 최근 본 GPU 카드
- `src/components/PriceChart.jsx`: 가격 그래프와 변경 이력 계산
- `src/styles.css`: 기존 시안의 디자인과 반응형 배치
- `src/services/data.js`: 가상 가격 데이터
- `src/services/marketApi.js`: 시연용 데이터 조회·로그인·답변 함수. 향후 백엔드 연결 위치
- `public/assets/`: 로고, 캐릭터, 글꼴
- `public/loading.html`, `public/404.html`: 기존 보조 화면

## 현재 범위

랜딩, 대시보드, 필터, 최근 본 GPU, 계약기간별 비교표, 가격 그래프, 변경 이력, 출처 상세, 모바일 메뉴, AI 패널, 데모 세션을 구현합니다.

가격·약정·이력은 기존 시안의 **가상 데이터**이며 GPU Finder 실제 수집본이 아닙니다. 최근 90일을 선택해도 샘플에 들어 있는 10월 이력만 표시됩니다. 약정 이력은 데모 가격 비율을 적용한 시각화이며 실제 관측 이력이 아닙니다.

로그인은 실제 계정을 만들지 않으며 비밀번호를 저장하거나 외부 서버에 전송하지 않습니다. AI는 실제 LLM이 아닌 규칙 기반 시연입니다. 백엔드·데이터·AI 연동은 별도로 필요합니다.

기존 정적 사이트와 공개 사이트는 변경하지 않았습니다.

## 배포용 파일 생성

```sh
npm run build
npm run preview
```

`dist/`에 배포용 파일이 생성됩니다. 현재 프로젝트는 로컬 개발용이며 자동으로 공개 사이트에 배포되지 않습니다.
